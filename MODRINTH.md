# GravesPro

[![Version](https://img.shields.io/badge/Version-1.0.0--SNAPSHOT-blue)](https://modrinth.com/plugin/gravespro)
[![Platform](https://img.shields.io/badge/Platform-Paper%20%7C%20Purpur-informational)](https://papermc.io)
[![Java](https://img.shields.io/badge/Java-21+-orange)](https://www.oracle.com/java/)
[![Minecraft](https://img.shields.io/badge/Minecraft-1.21+-green)](https://www.minecraft.net/)

GravesPro — це високопродуктивна система керування смертями для сучасних Minecraft серверів. Плагін забезпечує надійне збереження речей гравців після смерті, пропонуючи гнучкі налаштування для адміністраторів та інтуїтивно зрозумілий інтерфейс для користувачів.

## Основні можливості

### Просунута механіка могил
- **Автоматичне створення:** Могили з'являються миттєво на місці смерті гравця.
- **Налаштовувані блоки:** Можливість використання голів гравців або будь-яких інших блоків як маркерів.
- **Система терміну дії:** Автоматичне видалення могил після закінчення встановленого часу.
- **Збереження досвіду:** Можливість зберігання досвіду (XP) з налаштовуваним відсотком повернення.

### Інтуїтивний інтерфейс
- **Grave View GUI:** Чистий та зрозумілий інтерфейс для перегляду вмісту могили, причини смерті та координат.
- **Система відновлення:** Просте відновлення речей через GUI або фізичну взаємодію з могилою.
- **Історія смертей:** Доступ до списку попередніх смертей для гравців та адміністраторів.

### Візуалізація та ефекти
- **Вбудовані голограми:** Використання нативних Display Entities для високої продуктивності без потреби у сторонніх плагінах.
- **Ефекти частинок:** Візуальні підказки для полегшення пошуку могили.
- **Підтримка кастомних моделей:** Глибока інтеграція з Oraxen, ItemsAdder та Nexo для унікального вигляду могил.

### Безпека та захист
- **Приватність:** Можливість блокування доступу до могили іншим гравцям.
- **Доступ для команд:** Підтримка спільного доступу до речей для членів однієї команди.
- **Захист від середовища:** Могили захищені від вибухів, вогню та несанкціонованого руйнування блоків.

### Продуктивність та надійність
- **Підтримка баз даних:** Вибір між SQLite для невеликих проектів та MySQL для великих мереж.
- **Оптимізований код:** Мінімальний вплив на показник MSPT сервера.
- **Гнучкий API:** Можливість розширення функціоналу для розробників.

## Інтеграції
- **PlaceholderAPI:** Повна підтримка плейсхолдерів у голограмах та повідомленнях.
- **DecentHolograms / CMI:** Опціональна підтримка зовнішніх провайдерів голограм.
- **Провайдери предметів:** Сумісність з Oraxen, ItemsAdder та Nexo.

## Команди та права
- `/grave` — Основна команда для гравців (`gravespro.use`)
- `/grave history` — Перегляд власної історії смертей.
- `/grave admin` — Адміністративні інструменти для керування могилами (`gravespro.admin`)

---
**Зауваження:** Плагін розроблений для роботи на версіях Minecraft 1.21+ та потребує Java 21 для коректного функціонування.
